# Bài Tập: Thực Hành Sử Dụng Thẻ Liên Kết Trong HTML (HTML Links)

Bài tập thực hành các loại liên kết (`<a>`) trong HTML5 bao gồm liên kết ngoài mở tab mới (`target="_blank"`), liên kết ngoài thông thường, liên kết nội bộ và liên kết gửi thư (`mailto:`).

## 📋 Cấu trúc tệp

- `index.html`: Trang chính hiển thị danh sách các liên kết yêu thích.
- `about.html`: Trang giới thiệu nội bộ có nút quay về trang chủ.

## 🚀 Cách mở xem
Mở trực tiếp tệp [`index.html`](index.html) bằng trình duyệt web bất kỳ (Chrome, Edge, Firefox,...).
